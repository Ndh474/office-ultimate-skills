# Interoperability and conversion

Decide whether the user needs an editable workbook, a data extract, or a visual result. Those are different outputs.

## CSV, TSV, and ODS

`convert` supports XLSX to or from CSV/TSV, and XLSX to or from ODS through LibreOffice. It can also extract CSV, TSV or ODS from an existing XLSM. Those outputs do not carry VBA; the XLSM source stays intact and LibreOffice receives a macro-free copy. If VBA functions could affect the converted result, recalculated CSV/TSV and ODS export refuse with `MACRO_CALCULATION_UNSAFE`; stored-value CSV/TSV export remains available and labels values as stored. Native conversion also refuses active/external-refresh content or incomplete safety coverage; ODS input is checked for scripts/events/embedded documents and externally loaded resources before Calc sees it. Embedded chart subdocuments are not supported by this safe ODS lane, so chart-bearing XLSX-to-ODS may refuse at output validation, and ODS with such objects refuses as input. Converting XLSM to XLSX, or creating an XLSM through conversion, is refused. CSV/TSV carry a single tabular text stream, not multiple sheets, charts, formatting, validation, comments, or workbook metadata. On export, select the sheet and decide whether the extract should contain stored/cached values or formula text. On import, `--typed` permits unambiguous booleans/numbers; `--dates` additionally requires `--typed` and only converts real ISO calendar dates. Leading-zero identifiers, unsafe integers and decimal text that would lose precision remain text. Without coercion flags, preserve text. An imported string beginning with `=` remains literal, not a formula.

CSV/TSV parsing preserves a leading UTF-8 BOM as encoding metadata, embedded quoted newlines and quoted-empty records; malformed quotes and invalid UTF-8 refuse. Input/output text is bounded to 64 MiB and the rectangular data extent to 1000000 cells. Recalculated export checks the exact private snapshot before native launch and checks the expanded used range afterward, including reported spill followers. Source files remain unchanged, including signed workbooks used only for data extraction.

Options apply only to their stated conversion: `--sheet` is for delimited import/export, `--formulas` for delimited export, `--typed`/`--dates` for delimited import, and `--libreoffice-path`/`--timeout` for ODS. Irrelevant options refuse rather than silently changing scope. In particular, ODS conversion is whole-workbook and rejects `--sheet`.

Before handing off a conversion, inspect representative rows for delimiter, quoting, encoding, leading zeros, dates, booleans, numeric precision, and blanks. For ODS, compare critical workbook content and appearance in the destination application when those properties matter to the user.

## Round trips through another application

The skill does not talk to cloud spreadsheet services. When a workbook has been through another application, such as a file the user uploaded to and downloaded from a cloud service, compare the facts that matter to the request: sheet names, used ranges, selected values and formulas, tables, charts and validation when in scope, and a relevant rendered view when appearance matters. `interop compare` reports bounded package differences between XLSX or XLSM files; those differences guide inspection but do not settle application-level behavior by themselves.

`interop diff <before> <after> --max-changes <n>` compares stored cells by value, formula text and metadata, type and style index, reports sheets added, removed or reordered, and summarizes counts of tables, names, conditional formatting, data validation and charts. It resolves shared-formula followers when their references can be translated safely. Its cell list is bounded and marked truncated when needed. `compared_equal` covers only those fields; it is `null` when an unsupported sheet kind or unresolved shared formula makes cell coverage partial. Unlike package comparison, the diff includes cell contents; treat its output as workbook data. It does not compare object contents, interpret styles visually, recalculate formulas or establish application fidelity.
